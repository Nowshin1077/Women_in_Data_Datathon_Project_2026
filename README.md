## Key Findings

* **Low Diversity Baseline:** Only 49.9% of Ghanaian women achieve Minimum Dietary Diversity (MDD-W).
* **Divergent Supply Shifts:** Per-capita meat supply grew +32.0%, while vegetables (-40.7%) and pulses (-39.3%) dropped drastically.
* **Urban-Rural Disparity:** Egg intake reveals a 16.4 percentage point gap between rural (18.3%) and urban (34.7%) women.
* **Access vs. Supply Bottlenecks:** Stable egg production (+3.9%) indicates economic access barriers rather than supply shortages.
* **High-Impact Scenario: Shifting** 50% animal protein to plant sources boosts dietary iron by +55.2% and reaches ~2.2M additional people by lowering diet cost.

## Tools and Approach
* **Data Sources**: UN FAOSTAT (Food Balance Sheets, CoAHD, MDDW ).
* **Technical Stack**: Python 3 (pandas, numpy, matplotlib), Jupyter Notebooks, VS Code, Google Colaboratory, Git version control, and Streamlit.
* **Environment Reproducibility**: Resolved cross-platform configuration challenges across Mac, Windows, and cloud Jupyter environments using standardized YAML (`environment-windows.yml`) and requirements (`requirements.txt`) files.

* **Repository Architecture**:
  * `assets/`: Charts, diagrams, and Streamlit UI mockups.
  * `dataset/`: Cleaned three FAOSTAT datasets.
  * `notebooks/`: Exploratory Data Analysis and scenario simulation logic.
  * `src/`: Interactive Streamlit application source code.

---

## Impact
* **Interactive Decision Support**: Converts multi-layered data into an accessible Streamlit interface featuring three modules: 🔎 **Diagnose** (national supply trends), 📍 **Understand** (regional intake gaps), and 🥗 **Simulate** (scenario testing).
* **Shifting Policy Questions**: Transforms the policy dialogue from *"What should be on the plate?"* to *"What would it take to make that plate possible?"*.
